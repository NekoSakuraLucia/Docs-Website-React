## Docs Website - เว็บไซต์จัดการกับเอกสารแบบง่ายๆ

### วิธีการติดตั้งและใช้งาน
1. fork และ clone ก่อน
```bash
https://github.com/NekoSakuraLucia/Docs-Website-React.git
```

2. ติดตั้ง dependencies
```bash
bun install
```

3. รันเว็บไซต์
```bash
bun run dev
```
